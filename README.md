# 天晴傳－伏龍之章 遊戲資料站

《**天晴傳－伏龍之章**》（日文原名：**あっぱれ伝 ～伏龍の章～**；英文譯名：Appareden: The Sacrosanct Dragon）中文遊戲資料與攻略整理，收錄通關流程、劇情對話、角色、地圖、商店、敵人、道具、裝備、法術、遊戲公式與圖片，並提供線上存檔修改器。

瀏覽網站：**[天晴傳 遊戲資料站](https://catchtest.github.io/ApparedenGameArchive/)**

## 遊戲簡介

《天晴傳－伏龍之章》是日本 **TGL（Technical Group Laboratory）** 開發的回合制角色扮演遊戲，日文原版平台為 **NEC PC-9801**，繁體中文 DOS 版由 **松崗電腦** 代理發行。

本資料站以繁體中文 DOS 版的遊戲內容為主，整理幻斗與夥伴的冒險流程、各地事件及戰鬥資料，方便初次遊玩時查詢攻略，也供重溫劇情、比較角色能力與研究遊戲規則使用。

## 網站內容

- **流程與劇情**：依通關順序整理必經地點、迷宮路線、對話對象、任務物品取得與交付、隊員加入離隊及必要戰鬥；可配合地圖逐段閱讀主線對話。
- **主角與角色**：加入事件、初始能力、專屬技能、可用裝備、可習得法術，以及人物頭像與動作圖片。
- **地圖**：世界地圖、城鎮與迷宮配置、地點連接、場景人物、寶箱、商店、遇敵組和頭目。
- **商店**：按地點查詢販售商品，查看價格、用途與裝備能力，並連結到相關物品資料。
- **敵人**：能力值、弱點、抗性、戰鬥行動、掉落物與出現地點，搭配戰鬥圖片查閱。
- **裝備、道具與法術**：武器與防具的能力加成、攻擊回數、適用角色及取得來源；道具效果與作用對象；法術屬性、MP 消耗及習得條件。
- **公式與 BUG**：能力成長、升級所需業、普通攻擊與法術傷害、異常狀態及被偷襲判定，另整理遊戲中的設定錯誤、觸發條件與影響。
- **圖庫**：人物頭像、行走圖、戰鬥動作與過場圖片，可切換影格及放大檢視像素細節。
- **存檔修改**：載入遊戲存檔，調整隊伍、角色能力、裝備、技能、物品、金錢與所在位置，再匯出供遊戲讀取的存檔；亦提供示範存檔與 JSON 備份匯入匯出。
